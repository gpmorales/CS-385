# Bubble Cursor Evaluation

Bubble Cursor web-based implementation using HTML, CSS, and JS.
Tracks time, cursor distance, selections, and deselections.

## To Run Locally

$ npm install
$ node main.js

Then visit: http://localhost:3000

## Main Features

- Ctrl key toggles Bubble Cursor
- Blue attractor curve to nearest target
- Tracks and logs performance metrics
- CSV export of results
