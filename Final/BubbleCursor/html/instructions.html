Instructions

This experiment will take approximately 5 minutes to complete. Once all trials are completed, you will be given an overview of your performance.

Study Trial Overview

  • Targets: Circular items placed randomly on the screen. Some are green (valid), others are gray (distractors).
  • Selection: Move your cursor near a green target. The closest target will be highlighted in this blue and a blue curve that connects the target center with the Bubble Cursor's center.
  • Click to Confirm: Left-click to select the active target (indicated by the bubble lock). You will see a bold, yellow ring border appear on that target to indicate that you have selected it
  • Speed + Accuracy: Try to select all the green targets as fast and precisely as possible. Avoid selected non-green distractors.

Bubble Cursor Behavior

  • To enable the Bubble Cursor (bubble mode) simply press CTRL once. To disable press CTRL again.
  • The bubble radius changes dynamically based on target proximity.
  • The closest target is highlighted automatically and connected to the bubble cursor via a blue.
  • No need to perfectly align. Let the bubble and curve get close, connect, and click

Data Collected During Trials?

The system will automatically track the following metrics during each trial for both the traditional an:

  • Time Taken – How long it takes to complete each selection.
  • Correct Selections – Number of required targets selected.
  • Incorrect Selections – Number of extra/non-targets selected.
  • Deselection Actions – How often users undoes a selection.
  • Total Cursor Distance – How much distance the cursor moved throughout the trial while inside the demo area.
  • Overall Accuracy – The percentage of correct selections.
