Instructions

Welcome to my text entry evaluation study. This study is designed to assess how users interact with a swipe-based keyboard input technique.

Study Objective

During this study, you will either be asked to enter text using a custom swipe-based keyboard interface or a traditional keyboard. We will evaluate the efficiency of the gesture-driven text entry compared to traditional keyboard typing. Your speed and accuracy will be measured across multiple trials for both entry methods.

How to Use the SWIPE Keyboard



  • Entering Text: Press and hold the left mouse button. Move the cursor across keys to input letters. Keys are selected after a brief hover.
  • Selection Delay: A short delay (e.g., 250ms) is required while hovering over a key before it is selected to prevent accidental input.
  • Visual Feedback: As you swipe, a trail will appear and selected keys will briefly be highlighted.
  • Backspace: Use the RIGHT mouse button to remove the last character.
  • Auto Spacing: On the release of the left mouse button, assuming a word has been finished being selected, a space will be added automatically.
  • Practice Trials: You will begin with 5 practice trials to get comfortable with the technique.
  • Test Trials: You will then complete 15 timed test trials per block, for a total of 2 times/blocks (40 trials).

Data Collected During Trials

In each trial, you’ll be shown a phrase and asked to replicate it using the swipe keyboard. Try to match the phrase as accurately and quickly as possible

  • Time Taken – How long it takes to complete each phrase.
  • Input Accuracy – The number of correct vs. incorrect characters entered.
  • Keystroke Count – The total number of key selections.
  • Error Rate – The number of mistakes made during text entry.
  • Efficiency – Net words per minute (WPM) based on input quality and speed.
