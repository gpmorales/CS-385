Instructions

Welcome to my text entry evaluation study. This study is designed to assess how users interact with a swipe-based keyboard input technique.

Study Objective

During this study, you will be asked to enter text using a custom swipe-based keyboard interface. Instead of tapping individual keys, you will glide the cursor across letters to input text. This technique aims to evaluate the efficiency of gesture-driven text entry compared to traditional keyboard typing. Your speed and accuracy will be measured across multiple trials.

How to Use the Swipe Keyboard



  • Activate Brush Mode: Press the CTRL key to toggle the swipe brush. A custom cursor (a white circle with an “X”) will appear when the brush is active.
  • Entering Text: While in brush mode, press and hold the left mouse button. Move the cursor across keys to input letters. Keys are selected after a brief hover.
  • Selection Delay: A short delay (e.g., 250ms) is required while hovering over a key before it is selected to prevent accidental input.
  • Visual Feedback: As you swipe, a glowing trail will appear and selected keys will briefly highlight.
  • Backspace: If available, hover over the backspace key to remove the last character.
  • Practice Trials: You will begin with 5 practice trials to get comfortable with the technique.
  • Test Trials: You will then complete 15 timed test trials per block, for a total of 2 blocks (40 trials).

Data Collected During Trials

In each trial, you’ll be shown a phrase and asked to replicate it using the swipe keyboard. Try to match the phrase as accurately and quickly as possible

  • Time Taken – How long it takes to complete each phrase.
  • Input Accuracy – The number of correct vs. incorrect characters entered.
  • Keystroke Count – The total number of key selections.
  • Error Rate – The number of mistakes made during text entry.
  • Efficiency – Net words per minute (WPM) based on input quality and speed.
